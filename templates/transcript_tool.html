    How do you get a transcript from a YouTube video?

    Copy a direct video or Shorts URL, paste it above, and select Get transcript. When the video has publicly accessible captions, choose a language, read the timed text, then copy it or download TXT, SRT, or VTT. A video without captions cannot be transcribed by this tool.

    Which transcript file should you choose?

    TXT: plain text

    Best for reading, searchable notes, and quotations you will verify against the original video. The plain text export leaves out timestamps.

    SRT: timed subtitles

    Numbered cues with start and end times. Use this when your subtitle editor expects a .srt file.

    VTT: web captions

    WebVTT cues retain the same timing in a format used by web video players. All three exports come from the selected track.
