Estimate file size from bitrate

Enter the runtime and the bitrates of the streams you plan to save. This runs in your browser; it does not analyze or download a URL.

The starting values are an example, not a measured file. If the source gives no audio bitrate, enter 0; that estimate will exclude audio.

Video file size reference by bitrate

The 512 MiB preparation limit is roughly 0.54 decimal GB. Actual output can differ because bitrate varies and a finished container has overhead.

A source-reported byte count is more useful than this calculation. Variable bitrate, muxing and conversion can change the finished file. Read how YouTube streams and formats work before choosing a file.
