    FORMAT GUIDE

    Which format should you choose?

    JPG is widely compatible for photos but has no transparency. PNG keeps transparency and is useful for graphics, often with a larger file. WebP is a compact web format that can preserve transparency; its quality control can reduce file size, although a smaller result is not guaranteed. HEIC can be efficient for photos but may not open in older apps. Conversion cannot restore detail already lost from a source image.

    COMMON QUESTIONS

    Before you upload

    Will my images be stored?

    No. This batch is processed in memory, returned as a ZIP response and not added to media download history.

    What if one image is invalid?

    The whole batch stops with an error identifying which file needs attention. No partial ZIP is offered.

    Can I enlarge images?

    No. Resize only reduces width while keeping each image's aspect ratio.

    Does converting to PNG improve image quality?

    No. A PNG output does not restore detail lost in a JPG or other lossy source.
